# 问答题
1. 三个错误 分别是 访问空指针、执行敏感指令、读取sstatus寄存器
[rustsbi] RustSBI version 0.4.0-alpha.1, adapting to RISC-V SBI v2.0.0

2. trap.S 
    1. restore 是从内核太返回到用户态，所以sp一开始存放的内核态堆栈指针
    2. sstatus 记录supervisor模式的运行状态、sepc 保存用户态进程的指令地址、sscratch 在trap时保存用户栈指针。
    3. 这个在上面save的阶段已经备注，x2就是sp寄存器 这里里面存放了内核栈指针 需要先取回 再写。x4 当前没有使用。
    4. 交换后，sp存放用户栈指针，sscratch存放内核栈指针
    5. csrrw sp, sscratch, sp 这一步发生状态切换，下一步会从sp寄存器中读取指令。
    6. 用户态切换到内核态，sscratch保存用户栈指针
    7. call trap_handler ，进入S态开始执行 trap处理函数
